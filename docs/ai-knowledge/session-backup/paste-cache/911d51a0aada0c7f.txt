==================================================
External Search Policy
==================================================

اگر برای یک تصمیم Evidence کافی در Research Corpus وجود ندارد، جست‌وجوی خارجی انجام بده.

اما Web Search نباید شرط ادامه کار باشد.

اگر ابزار یا سرویس جست‌وجو در دسترس نبود:

- از Research Corpus استفاده کن.
- Publisher / DOI / Crossref / OpenAlex / University Repository / Author page را در صورت دسترسی بررسی کن.
- اگر هنوز قابل تأیید نیست، Pending Verification ثبت کن.

به یک سایت یا API وابسته نشو.

اگر:

403
404
429
Rate Limit
Paywall
API unavailable
Tool unavailable

رخ داد:

- retry بی‌نهایت نکن.
- به منبع معتبر دیگری برو.
- یا مورد را Pending Verification علامت بزن.

هرگز:

API unavailable = no paper

فرض نکن.

==================================================
نکته مهم درباره Proposal و Seminar
==================================================

Proposal و Seminar را:

- Scope/Constraint
در نظر بگیر،

اما:

- Scientific Truth مطلق
در نظر نگیر.

اگر Evidence علمی با آن‌ها تعارض دارد:

1. ادعا را مشخص کن.
2. Evidence را ارائه کن.
3. نوع مشکل را مشخص کن.
4. Minimum Scientifically Valid Correction را پیشنهاد بده.
5. بررسی کن آیا بدون تغییر Scope قابل اصلاح است.
6. اگر Scope تغییر می‌کند، آن را Human/Advisor Decision علامت بزن.
